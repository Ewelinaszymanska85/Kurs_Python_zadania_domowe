   tests/test_math.py::test_addition PASSED

8. W folderze:

   ad_4_pierwszy_test.yml

10. Środowisko Python 3.11 jest konfigurowane za pomocą:

    actions/setup-python@v5

11. Następnie workflow aktualizuje pip i instaluje
    zależności z pliku requirements.txt:

    python -m pip install --upgrade pip
    pip install -r requirements.txt

12. Testy są automatycznie uruchamiane poleceniem:

    pytest tests/ -v

13. Dzięki temu każda zmiana wysłana do repozytorium
